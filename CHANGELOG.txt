ComfyOnPoint Changelog

Version 1.12 - Beta - 27.09.2026
- Added reliable ComfyHub minimap bundling support.
- The standalone minimap button hides while bundled and returns when bundling is disabled.

Version 1.11 - Beta - 27.09.2026
- Renamed OnPoint to ComfyOnPoint as part of the Comfy Suite.
- Existing OnPointDB settings migrate automatically to ComfyOnPointDB.
- New commands: /comfyonpoint and /cop.
- Legacy /onpoint and /op commands remain available.

OnPoint Changelog

Version 1.5 - Beta - 26.09.2026
- Info tab now detects and shows the real running WoW client version, build and Interface.
- Shows whether the client's Interface matches OnPoint's tested Interface.
- GitHub now checks for newer WoW Forever builds automatically and opens a compatibility issue when needed.
- GitHub documentation now lists the mouse-following tooltip as the first/main feature.
- Interface versions are not blindly auto-approved; a quick in-game test is required before changing the TOC.

Version 1.4 - Beta - 26.09.2026
- Corrected the public author name to TheRealDoubleG everywhere.
- Added the official GitHub project URL to addon metadata, the Info tab and README.
- Prepared the source tree for the public GitHub repository.

1.3 Beta - 26.09.2026
- Optional pet/minion owner display.
- Pet mode added to the live preview.
- Minimap button now sits outside the minimap edge and its border is centered.
- Tooltip window scale option kept and clarified (50-150%).
- Existing custom profiles gain the new owner-display option automatically.
